🔑 API Keys: Public Key vs Secret Key

PopPay uses a two-key architecture similar to Stripe and Razorpay to ensure zero client-side credential exposure:

Key Type Prefix Where to Use Security Level
Public Key pp_live_... Frontend JavaScript & checkout.js SDK. Identifies your merchant profile, logo, and brand theme. Client-Safe
Secret Key pp_secret_... or pop_sec_... Backend server only. Passed in Authorization: Bearer <SECRET_KEY> to create orders. Server-Only (Private)
Webhook Secret whsec_... Backend webhook listener. Used to verify HMAC-SHA256 signatures in X-PopPay-Signature. Server-Only (Private)
Backend API Authorization Header 
Authorization: Bearer pp_secret_your_actual_key_here

⚠️ Security Rule: Always keep your Secret Key and Webhook Secret in backend environment variables (.env). Never commit them to Git or expose them in browser bundles.

2. Customer Checkout Experience

PopPay offers two flexible ways to present the checkout to your customers: an in-page popup modal (Recommended) using our lightweight SDK, or a direct hosted page redirect.

Option A: In-Page Checkout Modal (Recommended)

Modern & Fast

Customers never leave your website. Include our checkout.js script on your frontend, pass your Public Key (pp_live_...) and the order_id from your backend order creation call.

Frontend HTML & JavaScript Integration 
<!-- 1. Include PopPay SDK in your frontend HTML -->
<script src="https://poppay.tech/checkout.js"></script>

<!-- 2. Your checkout button -->
<button id="pay-button">Pay Now · ₹499</button>

<script>
document.getElementById('pay-button').addEventListener('click', async () => {
  try {
    // Step 1: Call your own backend endpoint to create a PopPay order
    const res = await fetch('/api/create-order', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ amount: '499.00' })
    });
    const order = await res.json(); // returns { order_id: "order_..." }

    // Step 2: Initialize PopPay with your PUBLIC KEY and order_id
    const pop = new PopPay({
      key: 'pp_live_YOUR_PUBLIC_KEY', // Public Key from PopPay Dashboard
      order_id: order.order_id,         // Order ID from your backend
      name: 'Acme Store',              // Store name displayed on modal
      handler: function (response) {
        // Called the moment payment is verified!
        console.log('Payment Successful!', response);
        // response object contains:
        // {
        //   order_id: "order_...",
        //   payment_id: "pop_pay_...",
        //   utr: "428910284729",
        //   signature: "a3f5..."
        // }
        window.location.href = '/order-success?order_id=' + response.order_id;
      },
      onDismiss: function () {
        console.log('Customer closed checkout modal');
      }
    });

    // Step 3: Open the checkout modal
    pop.open();
  } catch (err) {
    console.error('Checkout failed:', err);
    alert('Unable to initiate payment. Please try again.');
  }
});
</script>

3. Webhooks & Payment Reconciliation

Configure your Webhook URL in your PopPay Merchant Settings (e.g. https://myshop.com/webhooks/poppay). Whenever a payment is confirmed by the bank alert, PopPay sends an HTTP POST request with an HMAC-SHA256 signature in the X-PopPay-Signature header.

Webhook Payload

Event: payment.success 
{
  "event": "payment.success",
  "order_id": "pop_ord_8f4b23e198a2c10b",
  "payment_id": "pop_pay_71a93b49e102",
  "amount": "499.00",
  "utr": "428910284729",
  "receivedAt": "2026-10-18T10:36:12.000Z"
}

HMAC-SHA256 Signature Verification

Node.js / Express Webhook Handler 
import express from "express";
import { createHmac, timingSafeEqual } from "node:crypto";

const app = express();

// IMPORTANT: Use express.raw({ type: "application/json" }) to verify exact raw bytes
app.post(
  "/webhooks/poppay",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const signature = req.get("X-PopPay-Signature") || "";
    if (!/^[a-f0-9]{64}$/i.test(signature)) {
      return res.status(401).send("Invalid signature format");
    }

    const expected = createHmac("sha256", process.env.POPPAY_WEBHOOK_SECRET)
      .update(req.body)
      .digest();

    const received = Buffer.from(signature, "hex");

    if (received.length !== expected.length || !timingSafeEqual(received, expected)) {
      return res.status(401).send("Signature mismatch");
    }

    const event = JSON.parse(req.body.toString("utf8"));
    if (event.event === "payment.success") {
      console.log(`Payment confirmed for Order: ${event.order_id}, UTR: ${event.utr}`);
      // TODO: Idempotently fulfill order, activate subscription, or credit user account
    }

    // Always respond with 200 OK
    return res.sendStatus(200);
  }
);

Node.js Example

Node.js (Fetch) 
const response = await fetch("https://poppay.tech/api/v1/orders", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.POPPAY_SECRET_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    amount: "499.00",
    receipt: "order_1001",
    redirectUrl: "https://myshop.com/thanks"
  })
});

if (!response.ok) {
  throw new Error(`PopPay error: ${await response.text()}`);
}

const order = await response.json();
console.log("Redirect customer to:", order.checkoutUrl);

Python Example

Python 3 (Requests) 
import os
import requests

response = requests.post(
    "https://poppay.tech/api/v1/orders",
    headers={
        "Authorization": f"Bearer {os.environ['POPPAY_SECRET_KEY']}",
        "Content-Type": "application/json"
    },
    json={
        "amount": "499.00",
        "receipt": "order_1001",
        "redirectUrl": "https://myshop.com/thanks"
    }
)
response.raise_for_status()
order = response.json()
print("Redirect customer to:", order["checkoutUrl"])
